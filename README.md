## 🚀 How to Run the Projects

### Clone the repository

```bash
git clone https://github.com/ShreyaMaity7/CODSOFT.git
cd CODSOFT/TASKS
```

---

### Run Task 1 - To-Do List Application

```bash
cd Task1
python ToDo_List_Application.py
```

---

### Run Task 2 - Calculator

```bash
cd Task2
python Calculator.py
```

---

### Run Task 3 - Password Generator

```bash
cd Task3
python Password_Generator.py
```
